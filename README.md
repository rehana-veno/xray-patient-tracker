# X-Ray Patient Tracker — Hackathon Project

## Idea
A beginner-friendly health-services web app for tracking fictional patient appointments, X-ray scan status, and report readiness in one dashboard.

## Problem
Small clinics and diagnostic centres may need a simple way to see which patients are scheduled, already scanned, or waiting for reports.

## Solution
This prototype provides:
- Patient record entry
- Appointment date and X-ray type
- Status tracking: Scheduled, Scanned, Report Ready
- Search by name or patient ID
- Status filtering
- Dashboard counts
- Browser local storage so demo records persist on the device

## Demo
Open `index.html` in any modern browser. No installation or internet connection is required.

## Important
This is a student hackathon prototype using fictional data only. It is not designed for real medical records and does not provide medical advice.

## Suggested submission explanation
"My project is an X-Ray Patient Tracker designed for health services. It brings appointment details, scan status, and report readiness into one simple dashboard. The goal is to reduce confusion, make patient workflow easier to track, and give staff a quick view of pending and completed records. I chose this idea because it connects technology with my interest in the diagnostic imaging field."
